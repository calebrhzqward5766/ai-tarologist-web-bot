## Using the Bot

Connect the application to Telegram, open the bot, and send a tarot question or request for a reading.

A normal session looks like this:

1. Navigate to the Telegram bot.
2. Begin the conversation.
3. Send a question or ask for a tarot reading.
4. Read the resulting AI-generated response.
5. Launch the Mini App for the browser-based companion experience when needed.

For deployments with customized bot options, configure those values before launching the service. This allows the Telegram connection and Mini App to initialize as expected.

## Frequently Asked Questions

**How can I update the installation?**  
Use the newest release or build link available in the repository, then replace the files in the current deployment with the updated version.

**Where are the Telegram bot options configured?**  
Find the environment settings or configuration file associated with the Telegram bot and Mini App. Its location depends on the deployment structure.

**Why is the bot not replying?**  
Check that the Telegram token and hosting URL are correct, and confirm that the service was started according to the project instructions. The bot and Mini App endpoints must also be accessible.

**Is the Mini App usable on its own?**  
The Mini App is designed to operate as part of this project. Whether it is available independently depends on the way the repository is deployed and linked with Telegram.
